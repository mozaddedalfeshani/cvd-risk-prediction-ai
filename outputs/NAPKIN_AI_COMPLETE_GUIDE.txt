---BEGIN PROMPT---

Create a UML sequence diagram showing 14 steps for CVD Risk Prediction:

Participants: Doctor, Frontend (React), Backend (Flask), ML Model (SVM)

Steps:
1. Doctor inputs 17 medical values (Age, Weight, BMI, BP, Cholesterol, etc.)
2. Doctor clicks "Predict Risk" button
3. Frontend sends HTTPS POST request with JSON data to Backend
4. Backend validates input data format
5. Backend scales/normalizes features (0-1) and encodes categories
6. Backend loads trained SVM model (svm_model.pkl)
7. Model prepares 17-feature input vector
8. Model runs SVM algorithm on trained patterns
9. Model calculates prediction (0=NON-HIGH, 1=HIGH) + confidence
10. Model returns prediction result to Backend
11. Backend formats JSON response with interpretation
12. Backend sends HTTPS 200 response to Frontend
13. Frontend displays HIGH RISK (🔴) or NON-HIGH RISK (🟢) result
14. Doctor reviews and takes clinical action

Include: Color coding, timing <2sec, HTTPS security, audit logging

---END PROMPT---

STEP-BY-STEP INSTRUCTIONS FOR NAPKIN AI:
================================================================================

1. OPEN NAPKIN AI
   → Go to: https://napkin.ai
   → Create account (if needed) or sign in

2. CREATE NEW DIAGRAM
   → Click "New Diagram" or "Create"
   → Select "Sequence Diagram" option
   → OR click "Diagram Type" and search "Sequence"

3. PASTE PROMPT
   → Find the input box (usually on left side)
   → Click in the text area
   → Paste the prompt above (Option 1 or 2)
   → Press Enter or click "Generate"

4. WAIT FOR GENERATION
   → Napkin AI will process the prompt
   → Takes 5-30 seconds typically
   → You'll see the diagram appear on the canvas

5. REVIEW AND REFINE
   If you want to make adjustments, you can ask Napkin:
   - "Make the font larger"
   - "Add timing annotations"
   - "Use more vibrant colors"
   - "Emphasize the model steps"
   - "Add error handling paths"

6. EXPORT DIAGRAM
   → Click "Export" or "Download"
   → Choose format: PNG, SVG, or PDF
   → PNG is recommended for presentations
   → SVG for printing/editing

7. SAVE IN PROJECT
   → Save the file as: Sequence_Diagram_13_Steps.png
   → Store in: ml-models/outputs/

❓ TROUBLESHOOTING:
================================================================================

ISSUE: Napkin AI doesn't generate diagram
SOLUTION: 
- Try the Concise version (Option 2)
- Simplify the prompt
- Try again in a new session

ISSUE: Colors don't match what I wanted
SOLUTION:
- Manually edit after generation
- Ask Napkin to "adjust colors to..."
- Use Mermaid live instead (more control)

ISSUE: Text is too small
SOLUTION:
- Ask Napkin to "increase font size"
- Export at higher resolution (4K)
- Edit in image editor after export

ISSUE: Too many steps/cluttered
SOLUTION:
- Split into 2 diagrams (Frontend steps vs Backend steps)
- Use Option 2 (Concise) prompt
- Remove non-essential steps

ISSUE: Diagram doesn't show all 14 steps
SOLUTION:
- Restart and use Option 1 (Detailed)
- Paste prompt again
- Check that all steps are numbered 1-14
