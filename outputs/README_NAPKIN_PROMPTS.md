## 🚀 Quick Start (30 seconds)

### Step 1: Copy the prompt
From **NAPKIN_AI_COMPLETE_GUIDE.txt**, copy the "OPTION 1" prompt (most detailed)
or "OPTION 2" prompt (quicker)

### Step 2: Go to Napkin AI
Visit: https://napkin.ai

### Step 3: Create diagram
- Click "New Diagram"
- Select "Sequence Diagram"
- Paste the prompt into the text box
- Click "Generate"

### Step 4: Export
- Wait for diagram to generate (5-30 seconds)
- Click "Export" 
- Save as PNG
- Done! 🎉
