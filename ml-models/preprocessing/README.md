# Preprocessing Folder

## Purpose

This folder contains scripts that prepare raw data before model training.

## Structure

- `cleaning/`
  Scripts that create ML-ready datasets.
- `research/`
  Supporting research notes or analysis commands.

## Main Files

- `cleaning/clean_mymensing_dataset.py`
  Main cleaning pipeline for the Mymensing dataset.
- `cleaning/clean_generic_cvd_dataset.py`
  Generic cleaning pipeline for the broader CVD dataset.
- `research/research_analysis_commands.py`
  Research-oriented helper commands and notes.
