# Evaluation Folder

## Purpose

This folder keeps evaluation scripts separate from generated output files.

## Structure

- `scripts/`
  Utilities for plotting metrics, comparing models, and visualizing datasets.
- `reports/figures/`
  Saved PNG outputs.
- `reports/logs/`
  Saved training or evaluation logs.

## Main Files

- `scripts/plot_training_metrics.py`
- `scripts/plot_performance_comparison.py`
- `scripts/visualize_dataset.py`

## Rule of Thumb

Run files from `scripts/`, then check the outputs under `reports/`.
